# Verification and Validation: PubMed EN-ID Medical QA Benchmark (500 pairs)

Prepared by Moh. Nafik, S.Kep (IndoHealth-NLP), 6 November 2026.
Reproduced here as provided by the reviewer, formatted as Markdown.

## Dataset

- 500 question-answer pairs in English and Indonesian (EN-ID), built from
  PubMed abstracts (one abstract per pair).
- Task types: Diagnostic reasoning 169, Triage / referral 169,
  Medication / dosage 162.
- Each pair has a question and four options (A-D) in both languages, one
  marked correct answer, and a link to its source abstract.
- Questions were generated by Claude Opus 4.8 (20 August 2026), one per
  abstract. They had never been clinically reviewed before this
  verification. The review described below was that clinical check.

## Verification (does each pair match its source abstract?)

Every one of the 500 pairs was checked individually against its source
abstract, in 10 batches of 50 pairs (later split into sub-batches of 25
pairs per file, because a 50-pair file exceeded the upload size the
review tool could read in full).

Each pair was scored by an independent auditor (UI Gemini, model
Gemini 3.1 Pro) on seven criteria, and every score was cross-checked
by the reviewer (Moh. Nafik, IndoHealth-NLP) directly against the
abstract:

| Code | Criterion | Scale |
|---|---|---|
| U | Answerable from the abstract alone? | Yes / Partly / No |
| V | Exactly one option correct? | Yes / No |
| W | The marked answer is the correct one? | Yes / No |
| X | Wrong options plausible and clearly wrong? | Yes / Partly / No |
| Y | Clinically reasonable? | Yes / Unsure / No |
| Z | Indonesian translation faithful to the English? | Yes / Partly / No |
| AA | Rewritten options accepted? (compared with the first set of options for the same pair) | Yes / Partly / No |
| AB | Free comment / suggested fix | free text |

A pair was marked FATAL if V = No or W = No (i.e. more than one option
correct, or the marked answer is factually wrong according to the
abstract).

## Results

- First full pass (24 October 2026): 498 of 500 pairs passed all
  criteria; 2 pairs were FATAL and needed correction:
  - `pubmed-enid-02959` (row 111): the marked option stated the authors'
    initial hypothesis (MR arthrography more sensitive than standard
    MRI) as if proven, while the abstract concluded there was no
    statistically significant difference in sensitivity or specificity.
  - `pubmed-enid-03382` (row 458): the marked answer (SII) was claimed
    to independently predict surgical site infection, while the
    abstract concluded SII did not independently predict postoperative
    complication type or mortality.

  91 review comments were recorded in total (the 2 FATAL cases above
  plus 89 minor notes, mostly confirmations of translation fixes and
  option balancing from the earlier sample review).
- The author corrected both pairs. A re-audit of the two corrected
  pairs by the same independent auditor (6 November 2026) scored
  all Yes on U-AA for both, with 0 FATAL.
- Final result: 500 of 500 pairs clean.

## Validation (does the dataset as a whole hold together?)

- Answer-key balance: A / B / C / D = 125 / 125 / 125 / 125 (exactly
  balanced; the correct-letter position was shuffled when the wrong
  options were rewritten).
- Exactly one correct option per pair: confirmed for all 500 pairs
  (criterion V above).
- Distractors: all wrong options were rewritten to be specific,
  plausible and of comparable length to the correct option, and were
  checked to be clearly wrong according to the abstract (criterion X).
- Translation: Indonesian questions and options were checked for
  faithfulness to the English in every pair (criterion Z).
- Earlier checks the same review covers: a 150-pair sample review
  (20 October 2026, 150/150 reviewed, 2 wrong keys found and fixed),
  an independent re-audit of 58 pairs (58/58 agreed), and a content
  audit of the source corpus Vol.1 on a 100-pair random sample
  (100/100 passed).

## Limits

- Verification is against the source abstract only, not the full text
  of the article.
- The questions were generated from abstracts, not written by
  clinicians; the review above is the clinical accuracy check, not a
  substitute for clinical judgement in real patient care.
